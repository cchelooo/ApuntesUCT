# ApuntesUCT

Ecosistema colaborativo de material académico validado.

## Equipos

- INT2 — Web + Backend
- INT4 — Mobile

## Arquitectura

Microservicios + API Gateway.

## Tecnologías

### Backend
- Node.js
- TypeScript
- NestJS
- PostgreSQL
- Prisma
- MinIO

### Web
- React
- TypeScript
- Vite

### Mobile
- Flutter
- Dart
- Riverpod
- Dio
